# Codex instructions for 102CEM coursework

This repository contains Arduino/CEM coursework. Read the README and relevant `.ino` file before making changes.

## Priorities

1. Preserve the assignment requirements.
2. Keep Arduino code understandable and testable.
3. Explain hardware assumptions, wiring, libraries, and pin choices.
4. Avoid changing working behaviour without recording why.
5. Keep changes small and easy to compare.

## Collaboration

Codex and Claude may both work on this repository. Check the handoffs/, tasks/, and decisions/ directories before editing. After work, record changed files, reasoning, verification, hardware assumptions, and unresolved questions.

Do not claim hardware behaviour was verified unless it was actually tested on a board or clearly identified as untested.
