# AI collaboration protocol

## Before editing

- Read the README and relevant sketch.
- Identify the assignment or project goal.
- Check handoffs/, tasks/, and decisions/.
- Note hardware, board, pin, library, and wiring assumptions.

## During editing

- Keep the change focused.
- Preserve working assignment behaviour unless the task requires otherwise.
- Explain non-obvious Arduino logic.
- Do not commit credentials or private information.
- Do not claim physical verification without a real board test.

## Handoffs

Use handoffs/YYYY-MM-DD-assistant-topic.md and include the task, files changed, implementation summary, checks run, hardware tests, assumptions, unresolved questions, and recommended next action.
